
# Timeline Mar Jose

A timeline project for tracking and managing relationship moments.

## Features

- Create and manage timeline moments
- Organize events chronologically
- View event details and descriptions

## Getting Started

### Prerequisites

- Node.js (v14 or higher)
- npm or yarn

### Installation

```bash
git clone <repository-url>
cd timelineMarJose
npm install
```

`npx tailwindcss -i ./src/index.css -o ./src/tailwind.css --watch`

### Usage

```bash
npm start
```
